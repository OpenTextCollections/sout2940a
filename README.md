# Open Text Collections #2 
## Muyu texts

This collection features 14 texts from the Muyu language, spoken in New Guinea. 

This collection of ten texts offers a unique glimpse into the language and culture of the Muyu, a Papuan people living in the heart of New Guinea. It features narratives from six storytellers, all of which have been transcribed, translated, and linguistically annotated.

The files in this repository contain the texts in the CLDF and Elan/eaf formats. A human readable version of the book with anthropological and linguistic commentary is available under then name "Children of the sago: Muyu texts" at https://zenodo.org/records/15781820.
